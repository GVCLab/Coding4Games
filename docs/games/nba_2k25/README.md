# NBA 2K25

Launch the installed `NBA2K25.exe` and verify that the offline **Blacktop
1v1** route is available. The formal scenario `nba_2k25` uses Joel Embiid
against CPU Tyrese Maxey. The registered process-only start needs no
checkpoint ZIP. [Driver](../../../games/nba_2k25.yaml)

- Use a visible 1920×1200 client with the calibrated Chinese menus and HUD.
  The recorded startup includes initial keyboard confirmations. Gameplay
  uses raw `gamepad`, with process freezing and no xSpeed component.
- Verify the frozen 0:0 handoff. The 1000-tic task settles from the last
  retained native frame with +15 per own point and −5 per opposing point.
  Both labeled counters must be complete. A cropped or animating counter
  yields a null score when unreadable at the endpoint. The host retains the
  endpoint frame and its index, tic, and settlement diagnostics.
