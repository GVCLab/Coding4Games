# Slay the Spire

Use the build that launches `SlayTheSpire.exe`. The formal
`slay_the_spire` scenario requires `snapshots/slay_the_spire_golden.zip`.
The ZIP contains the registered `preferences/` tree and restores into the
game installation directory. Set the exact local restore destination and
review its contents before the first restore. [Driver](../../../games/slay_the_spire.yaml)

- Use an English, 1280×960 windowed client. Create the startup pad before
  launch so the game detects it. The default gameplay input is
  `gamepad-kbm`.
- Verify the fresh Ironclad Floor 1 start and full 80/80 HP handoff. The
  1000-tic task scores the highest confirmed floor reached.
