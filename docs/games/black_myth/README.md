# Black Myth: Wukong

The formal `black_myth` task starts at the registered **Black Bear Guai**
encounter. Install the build with `b1-Win64-Shipping.exe`. Set an explicit
account-compatible restore target under the installation's
`b1/Saved/SaveGames/` and provide `snapshots/black_myth_golden.zip`.
Verify the selected slot and boss start before replaying the menu recording.
[Driver](../../../games/black_myth.yaml)

- Use a visible 1280×720 client with DXcam and the registered Chinese HUD.
- The default development input is `gamepad-kbm`. The driver uses process
  freezing without xSpeed.
- The cap is 10000 tics at 10 Hz. Scoring is the maximum confirmed boss
  vitality depleted, on a 0–100 scale. Verify the initial full boss bar.
