# Aim Lab

The formal scenario is `aimlab`. Launch the Steam installation through app
`714010` and sign in before recording or testing. The game process is
`AimLab_tb.exe`. [Driver](../../../games/aimlab.yaml)

- Use **Gridshot 3x3 by whoisaqua** in English with a 2048×1152 windowed client.
- The registered preparation is a process-only cold start. Supply the
  account and the correct task in its playlist. There is no checkpoint ZIP.
- The default development input is `gamepad-kbm`. The DXcam client must be
  visible and the matching xSpeed components must control the round clock.
- Verify that the recorded navigation reaches the task. The episode cap is
  350 tics at 10 Hz for the 30-second task and results transition, with a
  240-call cap where applicable. There are no intermediate OCR terminal checks.
  Settlement requires the task identity and labeled Targets Killed or the
  Hits/Shots numerator. An unreadable result stays null.
